# Quran content

Susun Ayat shows Quran text only from a verified source, verbatim, with its
license and provenance kept next to the data. No Quran text, translation, or
answer key is ever written by hand or generated by AI.

## Surah metadata (hafalan tracker)

`src/data/quran/surahs.tanzil-uthmani.json` holds the Arabic name and ayah
count of all 114 surahs (6236 ayat), no Quran text. It is generated from the
same `quran-uthmani.xml` (same md5) with:

```bash
node scripts/extract-tanzil-metadata.mjs path/to/quran-uthmani.xml \
  src/data/quran/surahs.tanzil-uthmani.json --obtained-via "<how>"
```

Latin surah names exist only for the 10 bundled surahs (`SURAH_NAMES`);
others are shown as "Surah N" with the Arabic name.

## Adding or refreshing a surah

```bash
# 1. Download the Uthmani XML from https://tanzil.net/download/ (agree to the terms).
# 2. Extract verbatim; never edit the output by hand.
node scripts/extract-tanzil-surah.mjs path/to/quran-uthmani.xml 1 \
  src/games/susun-ayat/content/quran/001-al-fatihah.tanzil-uthmani.json \
  --obtained-via "tanzil.net download, <date>"
# 3. Register it in content/quran/index.ts, add levels, bump CONTENT_VERSION.
npm test
```

The script refuses files without the Tanzil copyright block, stores the
block verbatim, records md5/sha256 of the source file, and stores a hash of
the ayah texts that `content.test.ts` re-checks.

## Word segmentation

`orderWords` challenges split each verbatim ayah at the ASCII space (U+0020)
and nothing else (`content/segmentation.ts`). Every character, including
harakat and small marks, stays with its word, and the words joined with one
space equal the source text (tested for every bundled ayah). The bundled
text has no standalone pause-mark tokens; text that has them is refused
until a reviewed attachment rule exists. Source references for words are
`{ surah, ayah, word }` with a 1-based word index.

## Challenges (44)

Difficulty rules (`DIFFICULTY_RULES`): Beginner 2–4 pieces, Medium 4–7,
Hard 8–12, Expert 13–20 without ayah breaks. Free = Al-Fatihah, An-Nas,
Al-Falaq.

| Surah | Order ayat | Order words |
| --- | --- | --- |
| Al-Fatihah (free) | 1–3, 3–5, 5–7, 1–5, 1–7 | ayah 2, ayah 5, ayah 7, 5–7 |
| An-Nas (free) | 1–3, 1–6 | ayah 1, 4–6 |
| Al-Falaq (free) | 1–5 | ayah 1, 2–3, 1–3 |
| Al-Ikhlas | 1–4 | ayah 1, ayah 4, 1–4 |
| An-Nasr | 1–3 | ayah 1, ayah 2, 2–3 |
| Al-Kafirun | 1–6 | ayah 2, ayah 4 |
| Al-Kautsar | 1–3 | ayah 1, ayah 3, 1–3 |
| Al-Ma‘un | 1–3, 4–7 | ayah 1, 1–3 |
| Quraisy | 1–4 | 1–2, ayah 4, 3–4 |
| Al-‘Asr | 1–3 | ayah 2, ayah 3, 1–3 |

Ranges were chosen to avoid presenting a fragment whose meaning changes when
read alone (for example Al-Ma‘un 4 appears only together with 5–7). This is
a developer's judgement and needs review.
